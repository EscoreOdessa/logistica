# Витрати на доставку обладнання

Калькулятор вартості рейсу (постачальник → склад → клієнт) з картою Одеси та журналом рейсів.
Працює як статична сторінка на GitHub Pages: https://escoreodessa.github.io/logistica/

## Як рахується
- **Пальне** = км × витрата (л/100 км) / 100 × ціна літра (бензин або дизель)
- **Амортизація** = км × амортизація, грн/км (вводиться вручну для кожної машини)
- **ТО / ремонт** = км × ТО/ремонт, грн/км (вводиться вручну для кожної машини)
- **Разом** = пальне + амортизація + ТО/ремонт

Вид пального, витрату та ціну можна змінювати прямо в калькуляторі.
Машини з їхніми параметрами — на вкладці «Машини та адреси».

## Карта та кілометраж
Точки маршруту вводяться адресою з підказками (можна писати й російською) або кліком по карті.
Кілометраж кожної ділянки рахується дорогами автоматично; його можна виправити вручну.
Сервіси на даних OpenStreetMap без ключів: карта — tile.openstreetmap.org (Leaflet),
пошук адрес — Photon, резерв — Nominatim, маршрут — публічний сервер OSRM.
Адреси сервісів задаються в об'єкті `MAP` на початку скрипту.

## Де зберігаються дані
У браузері (localStorage) — у кожного комп'ютера/браузера свій журнал.
Робіть резервну копію: вкладка «Журнал рейсів» → «Зберегти копію».
Сховище винесене в об'єкт `store` на початку скрипту — щоб перейти на спільну базу
(Google-таблиця, API облікової системи), достатньо замінити його.

## Вивантаження
Excel (.xlsx) і CSV (роздільник `;`, UTF-8) — плоска таблиця, придатна для імпорту в облікову систему.
