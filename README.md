# Расходы на доставку оборудования

Калькулятор стоимости рейса (поставщик → склад → клиент) и журнал рейсов.
Учитывает топливо (отдельный расход с грузом и порожняком), амортизацию машины,
ТО/шины, платные дороги и оплату водителя. Работает как статическая страница на GitHub Pages.

## Как запустить на GitHub Pages
1. Положите `index.html` в корень репозитория (ветка `main`).
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `/ (root)` → Save.
3. Через 1–2 минуты страница откроется по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

## Карта и километраж
Точки маршрута (склад, поставщик, клиент) вводятся адресом с подсказками или кликом по карте.
Километраж каждого участка считается по дорогам автоматически; его можно поправить вручную.
Используются бесплатные сервисы на данных OpenStreetMap без ключей:
- карта — tile.openstreetmap.org (Leaflet);
- поиск адресов — Photon (komoot), резерв — Nominatim;
- маршрут — публичный сервер OSRM (router.project-osrm.org).

Публичные серверы рассчитаны на небольшую нагрузку (десятки запросов в день — нормально).
Если понадобится надёжнее, адреса сервисов меняются в объекте `MAP` в начале скрипта
(OpenRouteService, GraphHopper или Google Maps — с бесплатным API-ключом).

## Как считается
- **Топливо** = км с грузом × расход с грузом / 100 × цена + км порожняком × расход порожняком / 100 × цена
- **Амортизация, грн/км** = (цена покупки − стоимость при продаже) / пробег за срок владения
- **ТО и шины** = км × грн/км
- **Итого** = топливо + амортизация + ТО + дороги + водитель

Параметры задаются отдельно для каждой машины (вкладка «Машины»), можно завести
несколько марок и сравнить, сколько стоил бы тот же рейс на каждой.

## Где хранятся данные
В браузере (localStorage) — у каждого компьютера/браузера свой журнал.
Делайте резервную копию (вкладка «Журнал» → «Сохранить копию»).
Хранилище вынесено в объект `store` в начале скрипта: чтобы перейти на общую базу
(Google-таблица, API учётной системы), достаточно заменить его.

## Выгрузка
Excel (.xlsx) и CSV (разделитель `;`, UTF-8) — плоская таблица с колонками,
пригодная для импорта в учётную систему.
