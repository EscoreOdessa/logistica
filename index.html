Google-таблиця

Підключіть Google-таблицю — і журнал стане спільним: рейси з усіх комп'ютерів і телефонів записуються в одну таблицю, а тут показуються з неї.

Колега відкриває це посилання — і калькулятор одразу підключається до таблиці.
Як підключити таблицю (5 хвилин, один раз)
  1. Створіть нову Google-таблицю, наприклад «Журнал рейсів».
  2. У таблиці: Розширення → Apps Script. Видаліть усе в редакторі.
  3. і вставте його в редактор, натисніть «Зберегти». Код також лежить у репозиторії: apps-script.gs.
  4. Розгорнути → Нове розгортання → тип «Веб-застосунок». Виконувати як: Я. Хто має доступ: Будь-хто. Натисніть «Розгорнути» і дозвольте доступ до таблиці.
  5. Скопіюйте URL веб-застосунку (закінчується на /exec), вставте вище й натисніть «Підключити».

Витрата пального та амортизація задаються для кожної машини окремо. Додайте кілька варіантів, щоб порівняти. Зміни діють для нових розрахунків; збережені рейси не перераховуються.

Google Maps

З ключем Google пошук адрес і кілометраж рахуються через Google (точніше за номерами будинків). Без ключа працює OpenStreetMap.

Як отримати ключ (один раз)
  1. Відкрийте console.cloud.google.com і створіть проєкт (наприклад, «logistica»).
  2. Billing → прив'яжіть картку (без неї Google не видає ключ; у межах безкоштовного ліміту списань немає).
  3. APIs & Services → Library → увімкніть: Maps JavaScript API, Places API (New), Routes API, Geocoding API.
  4. APIs & Services → Credentials → Create credentials → API key.
  5. У налаштуваннях ключа: Application restrictions → Websites → додайте https://escoreodessa.github.io/*; API restrictions → виберіть ці 4 API. Збережіть.
  6. Скопіюйте ключ і вставте вище.
